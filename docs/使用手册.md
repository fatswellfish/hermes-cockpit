# 项目中枢 · 使用手册

> 面向使用者的操作说明。安装、开发、改代码请看 [README.md](README.md)。

---

## 一句话

项目中枢把 **项目 → 会话 → todo** 串成一棵树，三个可展开的列：

```
列1 项目            列2 会话              列3 todo
                                          ├ 人看的主条目（要交付什么）
                                          └ 机器看的子步骤（逐项推进）
```

解决的问题：**会话会被压缩、溢出后新建，但 todo 不会跟着丢。**
todo 独立于会话存在，同时记着它当初是哪个会话引出的。

---

## 打开它

侧栏点 **Project Hub**（在「任务」和「看板」之间）。

第一次打开会看到两个按钮二选一，**这是单向门，选完不可改**：

| 按钮 | 什么时候选 |
|---|---|
| 📥 **导入已有** | 你机器上已经有一堆项目和会话 ← **一般选这个** |
| 🆕 **从零开始** | 全新机器，什么都还没有 |

⚠️ 选错无法在界面上撤销，只能手工改 `META.yaml` 的 `setup` 段。

---

## 三类 todo，存在三个文件

| 类型 | 文件 | 谁写 | 放什么 |
|---|---|---|---|
| **agent 自动化** | `TASKS.agent.md` | **agent 自己写**（做完一步勾一笔） | 你让 agent 干的活、它正在做的进度 |
| **办公日常** | `TASKS.work.md` | 你写 | 报价、合同、客户沟通、内部协调、报表 |
| **家庭** | `TASKS.home.md` | 你写 | 家里要办的事、亲戚往来、孩子的事 |

三份都在 `C:\dev\software-projects\hermes-cockpit\` 下。

**人看 vs 机器看**：主条目是人看的（「这次要交付什么」），下面挂的子步骤是机器看的（「逐项推进到哪了」）。
子步骤勾完，主条目进度自动跟着涨。**机器那层 agent 自己写，你只负责看。**

```
│  └ 软件开发 · 社交分析
├ Media · 2
└ 未归属
```

**项目层还有一份汇总**：项目下所有 todo 直接列出，不用一层层翻。

## 七个操作

### 1. 给会话归到某个项目 ← 最常用

列2 的「未归属会话」里找到它 → 选项目 → 点 **`归类`**。

- 只写 `META.yaml`，**不动 `sessions.cwd`**（cwd 一改会话就废，硬边界）
- 标了 `manual` 的优先级最高，不会被 cwd 自动判断覆盖

### 2. 在项目里新建会话

选中项目 → 列2 顶部 **`＋ 新建会话`**。在项目目录下建，建完自动回查 cwd 落对没有。

### 3. 新建一条 todo

在对应文件里写（例如 `TASKS.home.md`）：

```markdown
## T-006 给孩子约体检 · todo · 0%

- [ ] T-006.1 查社区医院时间
- [ ] T-006.2 预约

**快照**：还没开始
**阻塞**：无
```

保存后界面自动刷新。要挂到某个会话就加一行 `> session: <会话id>`，不写就按项目归属。

### 4. 勾选子步骤

列3 里点子步骤前的方框。文件被别处改过时会先提示「文件已变化，正在刷新」，**不覆盖你手改的内容**。

### 5. 看阻塞

红色提示框 = 有阻塞。蓝色框是「快照」——当时的既定结论，不是待办。

### 6. 打开会话

列2 点会话标题 → 跳到那个会话。

### 7. 状态栏小灯

右下角状态栏有个小圆点 + 项目数/会话数（如 `14/1518`）：

- 颜色 = 有没有孤儿任务（任务说属于某项目，但项目表里没这个项目）
- **点它** = 直接跳到项目中枢

## 三个必须先知道的事

### ⚠️ 它不会自动帮你归类上千个会话

一开始你会看到「未归属」数量很大。这是正常的设计——插件不做批量自动归类，因为**猜错了比不猜更糟**。

按需一个个归（操作 1），或者让助理用关键词批量给建议、你逐条确认。

### ⚠️ 跑题提醒只问不拦

你在某个项目的会话里聊到别的项目，插件会提示，但**不会拦你**。拦人比跑题更烦。

### ⚠️ 看板是单向的

从这里看得到看板卡片，但**改不了**。看板归看板（那边内置插件管），项目中枢只管「看得见」。要改用看板。

## 出问题怎么办

| 现象 | 原因 | 怎么办 |
|---|---|---|
| 顶部红条 `unsupported import` | 插件文件装错 | 重跑 `bash scripts/install.sh` |
| 数据全是 0 | 引导没做 | 点「📥 导入已有」 |
| 显示英文 | 宿主语言是英文 | 改 `config.yaml` 的 `display.language: zh`，**重启 App** |
| 显示「只读」 | 引导没完成 | 完成引导后自动解除 |
| 勾选提示「文件已变化」 | 文件被别处改过 | 等刷新完再勾 |
| 侧栏找不到入口 | 插件没启用 | `hermes plugins list` 看有无 `project-hub` |
| todo 没出现在界面 | 文件格式不对 | 看该文件末尾「格式约定」；`##` 标题行必须带 id |
